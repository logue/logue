## 🚀 Featured Projects

- **[vue-codemirror6](https://github.com/logue/vue-codemirror6)**: CodeMirror 6 component for Vue 3. Roughly 280K npm downloads per month.
- **[vue-vrm](https://github.com/logue/vue-vrm)**: Render VRM avatars in Vue.
- **[vite-vuetify-ts-starter](https://github.com/logue/vite-vuetify-ts-starter)**: Starter template for Vue 3 apps with Vuetify and TypeScript, built on Vite.
- **[rstack-library-starter](https://github.com/logue/rstack-library-starter)**: Framework-agnostic starter template for TypeScript libraries on the Rstack (Rsbuild, Rslib, Rslint, Rstest).
- **[tauri-vuetify-starter](https://github.com/logue/tauri-vuetify-starter)**: Starter template for desktop apps with Tauri and Vuetify. The foundation of the two apps below.
- **[Drop Compress Image](https://github.com/logue/DropWebP)**: Desktop image compression tool.
- **[VRM2SL](https://github.com/logue/vrm2sl)**: Converts VRM avatars to Second Life avatars.
- **[umd-core](https://github.com/logue/umd-core)**: Universal Markdown parser written in Rust (experimental).
